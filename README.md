# Учёт трат

Учебный проект на Go: веб-приложение для личного учёта трат.
Есть регистрация, вход и выход. Каждый пользователь видит только свои траты.

## Что нужно

- Go 1.22 или новее (проверить: `go version`)
- Интернет при первом запуске, чтобы скачать зависимости

## Запуск

1. Откройте терминал в папке проекта (там, где лежит `go.mod`).

2. Скачайте зависимости:

   ```bash
   go get golang.org/x/crypto/bcrypt
   go mod tidy
   ```

3. Запустите сервер:

   ```bash
   go run .
   ```

4. Откройте в браузере: http://localhost:8080

Файл базы данных `expenses.db` и все таблицы создаются сами при первом запуске.

> Запускать нужно именно из корня проекта, иначе сервер не найдёт папки `migrations` и `web`.

## Как пользоваться

1. Нажмите «Регистрация», введите email и пароль (от 6 символов).
2. Добавляйте траты через кнопку «Добавить».
3. Чтобы проверить разграничение доступа, откройте сайт в режиме инкогнито и зарегистрируйте второго пользователя. Он не увидит чужие траты.
4. Кнопка «Выйти» завершает сессию.

## Структура проекта

```
main.go                  точка входа, маршруты
migrations/              SQL-миграции (применяются автоматически)
internal/models/         работа с базой: траты, категории, пользователи, сессии
internal/handlers/       обработчики страниц и авторизация
web/templates/           HTML-шаблоны
web/static/              стили
```

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| `no required module provides package ...bcrypt` | Выполните `go get golang.org/x/crypto/bcrypt` |
| Ошибка про шаблоны или миграции | Запустите `go run .` из корня проекта |
| Порт 8080 занят | Поменяйте порт в `main.go` (`http.ListenAndServe(":8080", ...)`) |
| Нужна чистая база | Остановите сервер, удалите `expenses.db`, запустите снова |
